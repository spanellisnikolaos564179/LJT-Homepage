# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io)).

## Site contents

- **About** (`/`): personal details, academic background, research experience, research interests, publications, honors and awards, and contact information.
- **Publications** (`/publications/`): the full publication list.
- **CV** (`/cv/`): education, research experience, skills, publications, and honors.

Site-wide settings (including the author sidebar and contact links) are in [`_config.yml`](_config.yml). Content pages live in `_pages/`, and each publication has a Markdown file in `_publications/`.
